# 项目目录与注释约定

游戏入口为 `scenes/ui/主菜单.tscn`，实际游戏场景为 `scenes/core/根节点.tscn`。业务脚本、场景、模型、材质、动画和验收按所属功能分目录；代码中的资源路径统一使用 `res://`。

| 目录 | 职责 |
| --- | --- |
| `scripts/core`、`scenes/core` | 游戏会话与入口组织 |
| `scripts/player`、`scenes/player`、`assets/models/player`、`animations/player` | 玩家输入、相机、模型与分层动画 |
| `scripts/combat`、`scenes/enemies`、`assets/models/enemies`、`animations/enemies` | 攻击、史莱姆与敌人动画 |
| `scripts/ui`、`scenes/ui`、`assets/ui`、`shaders/ui` | 菜单、聊天、生命条与小地图 |
| `scripts/world`、`scenes/world`、`shaders/terrain`、`shaders/water`、`shaders/sky` | 地图、天空和海面 |
| `scripts/clouds`、`shaders/clouds`、`materials/clouds`、`assets/clouds` | 共用体积云渲染和噪声 |
| `assets/models/terrain`、`materials/terrain`、`materials/sky` | 游戏地形模型及环境资源 |
| `tests/player`、`tests/combat`、`tests/world` | 玩家、对战与环境验收 |
| `tools/terrain` | Blender 路网与桥梁制作工具 |
| `source_art` | 美术源文件与制作数据，由 `.gdignore` 排除自动导入 |
| `source_art/terrain/exports` | 无桥路网制作中间导出；由制作工具生成，游戏不引用 |
| `source_art/archive` | 第一版地形及史莱姆修复前源文件，便于历史对照 |

所有脚本、着色器和制作工具顶部使用中文说明职责、协作关系及运行条件。GDScript 导出变量前使用 `##` 文档注释，说明用途、单位、实际影响和边界条件；着色器的 `uniform` 前使用中文 `//` 注释。标识符、动画名称、引擎 API 和资源 UID 保留原值。场景与资源使用合法的分号注释，Godot 编辑器重新保存时可能重写此类说明。

二进制模型、Blender 文件、纹理和自动生成的 `.uid`、`.import` 不插入文档注释，避免破坏格式或导入设置；其用途由本目录说明及 README 记录。JSON 文件保持标准格式，路网和桥梁采样由相应验收脚本读取。

本次移除隐藏的第一版地形节点和运行时 `超大地形.glb`，清除旧地图碰撞处理和注释掉的旧实现；当前地图仍按原有结构组合第二版模型及桥梁路网。无桥 GLB 转入制作目录并移除其导入配置。所有仍参与游戏、验收和道路桥梁重建的资源保留；历史源文件与 Blender 自动备份保留在制作目录。

运行方式和图形验收条件见 [项目说明](../README.md)。批量迁移时需一起更新场景、脚本、材质、工具及文档中的路径，并随脚本移动 `.uid`，随运行模型移动 `.import`，保持资源标识稳定。

碰撞验收按当前模型命名检查 32 根肋柱、10 段道路、塔及整平地形，共 44 个网格；原先只筛选单个「道路」节点的条件已更新，避免漏检分段路网。
